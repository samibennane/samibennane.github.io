01 Étape 1

Tokenisation :
découper le texte en tokens

Le modèle ne lit pas les mots — il lit des tokens, des fragments de texte. Un token ≈ ¾ d'un mot en français. Testez ci-dessous avec n'importe quelle phrase.

02 Étape 2

Embeddings :
les tokens deviennent des vecteurs

Chaque token est converti en un vecteur de plusieurs centaines de dimensions (768 pour GPT-2, 12 288 pour GPT-4). Ces chiffres capturent le sens du mot dans un espace géométrique.

Ces dimensions sont apprises pendant l'entraînement — le modèle a découvert que "deux", "trois" et "quatre" partagent des propriétés géométriques similaires.

Positional Encoding — savoir où on est

Contrairement aux RNN, le Transformer traite tous les tokens en parallèle. Il faut donc ajouter un encodage positionnel (sinusoïdes de fréquences variées) pour que le modèle sache si "deux" est le 3e ou le 7e token.

03 Étape 3

Self-Attention :
Q, K, V — la mécanique

C'est le cœur du Transformer. Pour chaque token, le modèle calcule trois projections : Query, Key, Value. L'attention mesure à quel point chaque token doit "regarder" les autres.

Query — Q
La question
Ce que ce token cherche. "Je suis deux, qu'est-ce qui me concerne ici ?" Chaque token envoie une requête vers tous les autres.
Key — K
L'étiquette
Ce que ce token offre. Chaque token expose une clé. Si la clé correspond à la Query, l'attention est forte — comme un index dans une base de données.
Value — V
Le contenu
L'information réelle transmise. Si l'attention entre Q et K est forte, la Value associée est fortement pondérée dans la somme finale.

Cliquez sur un token pour voir ses poids d'attention. L'épaisseur des traits = l'intensité de l'attention.

04 Étape 4

Softmax :
normaliser en probabilités

Les scores d'attention bruts (produits Q·Kᵀ) sont transformés en probabilités via la fonction softmax. La température contrôle à quel point la distribution est concentrée ou diffuse.

Température basse → le modèle est très sûr de lui, concentre tout sur le token le plus probable (réponse déterministe).
Température haute → la distribution s'aplatit, le modèle explore davantage (texte créatif, moins prévisible).

05 Étape 5

Feed-Forward Network :
la mémoire du modèle

Après l'attention, chaque token passe individuellement par un réseau de neurones (FFN). C'est ici que le modèle stocke ses "connaissances factuelles" — comme le fait que 2+2=4.

Entrée
d = 768
→
Couche cachée · ReLU
d × 4 = 3 072
→
Sortie

Le FFN est appliqué de façon identique et indépendante à chaque position. C'est la partie la plus "lourde" en paramètres (~⅔ des poids du modèle). Des études récentes montrent que certains neurones activent spécifiquement sur des faits précis.

06 Étape 6

Génération :
prédire le token suivant

Le modèle prédit un token à la fois, en mode autorégressif. À chaque étape, il choisit parmi le vocabulaire entier (~50 000 tokens). C'est ici qu'on voit le choix se faire.

Decoder-Only
